# @typedown-example/basic

A minimal project showing Typedown validating plain TypeScript snippets in
Markdown against the `node` types.

```bash
pnpm check:docs   # runs `typedown check`
```

See [`docs/intro.md`](docs/intro.md) for the validated snippets and
[`typedown.config.ts`](typedown.config.ts) for the configuration.
