# @kiira-example/basic

A minimal project showing Kiira validating plain TypeScript snippets in
Markdown against the `node` types.

```bash
pnpm check:docs   # runs `kiira check`
```

See [`docs/intro.md`](docs/intro.md) for the validated snippets and
[`kiira.config.ts`](kiira.config.ts) for the configuration.
